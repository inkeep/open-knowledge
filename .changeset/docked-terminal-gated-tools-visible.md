Agents launched from the docked terminal can once again use `move`, `delete`, `install`, `import`, and `share_link`. These five tools stay gated behind an approval prompt, as intended, but they are no longer withheld from the agent entirely, so an agent can rename a document (rewriting the wikilinks that point at it) or remove one without you doing it by hand. Turning off "Let agents use OpenKnowledge without asking" was never required to get them back.
