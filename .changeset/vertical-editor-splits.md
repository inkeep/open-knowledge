Add a resizable vertical split workspace with one shared header for tabs and
workspace actions. Drag tabs or sidebar files into pane edges, or use tab
actions, to create and populate panes. Pane sizes, open tabs, and focus restore
with the project session, while editor actions and the right document and agent
panels follow the focused pane below the header.

Polish tabs across single and split panes with stable sizing, horizontal
overflow scrolling, edge fades, clearer drag feedback, and shared actions for
documents, folders, and assets. Existing preview tabs keep their replaceable
and pinned behavior while supporting the same drag, split, and overflow
interactions as regular tabs.
