Agent lists in Settings now reflect what is actually on your machine. Skills folders and the Install menu offer only folders whose agent home already exists, so choosing one can no longer create an integration folder for a tool you do not have. Configure agents sorts the agents you can run to the top of each group, and puts groups that hold something above ones that hold nothing. AI tools & CLI puts the tools you use first, folds the rest, and no longer claims to have detected a tool it has not: an unconfigured row now links to its setup guide instead. Adding a folder before its tool arrives still works through Add custom path.
